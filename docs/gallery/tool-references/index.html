Hex-key sizing

The nine long-key envelopes in HX01 use published dimensions for 1.5–10 mm EGA Master keys. The generated reference has hexagonal shanks and a swept elbow with an assumed bend radius. The three downloaded short-key models provide an independent shape check. EGA Master dimensional table.

Tape-measure and cable coverage

The tape dock uses a conservative 92 × 48 mm case-plus-clip envelope. Several product listings mix case dimensions with retail packaging, so coverage is stated by envelope. The coil hanger uses a user-arranged bundle envelope. Their gray viewer shapes show those clearance assumptions.
